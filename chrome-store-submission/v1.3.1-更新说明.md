# knexio WebNote v1.3.1 更新说明

## 本版本更新内容（商店提交用）

### 中文版

**v1.3.1 更新内容：**

- 🎨 界面优化：全文/摘要操作按钮合并到同一行，布局更紧凑
- 🎨 按钮样式统一：同类按钮等宽设计，全文类按钮蓝色、摘要类按钮绿色，一目了然
- ✏️ 按钮文字优化：去除导出按钮标签中的括号，显示更简洁（如"导出全文MD"）
- 🐛 修复：摘要内容在 markdownmaster.site 编辑器中 nowrap 的问题，预览区自动换行恢复正常
- 🐛 修复：生成的摘要内容导出为 Markdown 时段落换行正确，不再出现单行溢出

---

### English Version

**What's new in v1.3.1:**

- 🎨 UI优化: Full-text and summary action buttons merged to the same row for a more compact layout
- 🎨 Unified button styles: equal-width buttons, color-coded by function (blue for full-text, green for summary)
- ✏️ Button label optimization: removed parentheses from export button labels for cleaner display (e.g. "导出全文MD")
- 🐛 Fix: summary content now wraps correctly in markdownmaster.site editor preview instead of showing as a single long line
- 🐛 Fix: paragraph line breaks now render correctly when exporting summary to Markdown

---
